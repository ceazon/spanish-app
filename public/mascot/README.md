# Chadlingo Mascot Assets

Drop exported mascot PNG files in this folder using these exact names:

- `chadlingo-default.png` (base style master #1)
- `chadlingo-success.png` (celebration/confetti)
- `chadlingo-progress.png` (pointing to progress)
- `chadlingo-streak.png` (sunglasses + flame)

The app references these paths directly:

- `/mascot/chadlingo-default.png`
- `/mascot/chadlingo-success.png`
- `/mascot/chadlingo-progress.png`
- `/mascot/chadlingo-streak.png`

Recommended export size: 1024x1024 PNG with transparent background.
